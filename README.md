# Portfólio de Análise de Dados e Business Intelligence

Bem-vindo(a) ao meu portfólio profissional. Este espaço reúne projetos práticos focados na resolução de problemas reais de negócios através de dados, utilizando ferramentas modernas de mercado.

## 🛠️ Tecnologias e Habilidades Utilizadas
* *Linguagens de Consulta e Programação:* SQL e Python (Pandas).
* *Visualização de Dados:* Looker Studio / Power BI.
* *Métricas de Negócio:* Churn Rate, ROI (Retorno sobre Investimento), CAC (Custo de Aquisição de Cliente) e Modelagem de Dados corporativos.

---

## 📁 Projetos Inclusos neste Repositório

### 1. Análise de Vendas e Monitoramento de Churn (SQL & BI)
* *Arquivo de Código:* analise_vendas_churn.sql
* *Painel Interativo:* [Clique aqui para abrir o Dashboard Visual](https://google.com)
* *O Problema:* Identificar clientes que pararam de comprar em um e-commerce para criar estratégias de retenção.
* *Solução:* Desenvolvimento de consultas em SQL para calcular a recência e classificação de risco, integrado a um painel executivo interativo para tomada de decisão da diretoria.

### 2. Otimização de Investimento de Marketing - ROI (Python)
* *Arquivo de Código:* analise_roi_marketing.py
* *O Problema:* Identificar a lucratividade real de canais de anúncios pagos de uma empresa de tecnologia.
* *Solução:* Script automatizado em Python estruturando o cálculo do ROI de forma dinâmica, apontando caminhos para corte de custos operacionais.

### 3. Data Cleaning e Tratamento de Banco de Dados de RH (SQL)
* *Arquivo de Código:* tratamento_dados_rh.sql
* *O Problema:* Base de colaboradores corrompida com registros duplicados e dados salariais ausentes.
* *Solução:* Processo de ETL via SQL utilizando ROW_NUMBER() e COALESCE para garantir a integridade dos relatórios da diretoria.
